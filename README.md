# Cymatic OS - Personal AI Operating System Template

**Eliminate AI conversation fragmentation forever.** Build a personalized AI system that knows you, understands your patterns, and speaks your language.

## What is Cymatic OS?

Cymatic OS is a complete personal AI operating system that:
- Maintains persistent context across all AI conversations
- Recognizes and interrupts your behavioral patterns
- Calibrates AI communication to your exact preferences
- Tracks your projects, goals, and success metrics
- Provides custom commands tailored to your needs

Think of it as giving AI a "user manual" for you.

## Quick Start

### 1. Clone this repository
```bash
git clone https://github.com/[YOUR-USERNAME]/cymatic-os-template.git
cd cymatic-os-template
```

### 2. Open in your IDE

Open the repository in VS Code (or your preferred IDE) with Claude Code installed.

### 3. Start the onboarding

In Claude Code, run:
```
/onboarding start
```

This launches the **Cymatic AI Architect** agent who will guide you through a 90-120 minute conversation to build your personalized AI operating system.

### 4. Complete the interview

The agent will walk you through 6 stages:
1. Identity & Operational Context
2. Behavioral Pattern Recognition
3. Communication Calibration
4. Project Ecosystem Mapping
5. Goals & Success Metrics
6. Intervention & Command Design

As you complete each stage, the agent automatically writes your personalized vault files.

### 5. Start using Cymatic

Once onboarding is complete, just start chatting with Claude Code normally. The **Cymatic agent** auto-loads your complete context from the vault files - every conversation will feel like talking to someone who truly knows you.

**Note:** You can pause anytime and resume with `/onboarding resume [stage]`

## What Gets Created

Your personalized Cymatic OS includes:

- **Identity Profile** - Your values, boundaries, success definition
- **Behavioral Patterns** - Recognized patterns with custom interventions
- **Communication Calibration** - Exactly how AI should talk to you
- **Project Ecosystem** - Your active work and focus areas
- **Goals & Metrics** - What success looks like for you
- **Custom Commands** - Tailored shortcuts for your specific needs

## How It Works

1. **Onboarding** - Conversational interview extracts your unique "frequency"
2. **Calibration** - System maps your patterns, preferences, and context
3. **Deployment** - Complete OS becomes AI's permanent instructions
4. **Evolution** - System updates as you grow and change
