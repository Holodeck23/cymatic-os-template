# 📝 Quick Capture Scratchpad

> Temporary parking lot for raw thoughts before filing

## How to Use
- Drop fast notes here during `/focus` or `/journal` cycles.
- Prefix each entry with `### YYYY-MM-DD – Context` for easy pruning.
- After processing, move the insight to the right vault file and replace it with `→ filed in [path]`.

## Template Block
```
### 2025-__-__ – [Trigger]
- Thought dump:
- Immediate action (if any):
- Destination file:
```
