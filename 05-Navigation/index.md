## 🎯 Daily Workflow

### Morning Activation (`::daily_start`)
1. Check [Current State](../01-Knowledge-Vault/current-state.md) → Update energy level
2. Review yesterday's commitment → Did you complete it?
3. Set ONE priority → "I will [action] by [time]"

### Work Session
4. Apply [DRIVE Framework](../00-Core-System/progress-core.md#drive-framework) → Detect → Refine → Implement → Validate → Evolve
5. Watch for [Behavioral Patterns](../01-Knowledge-Vault/behavioral-patterns.md) → Trigger interventions when needed

### Evening Review  
6. Update [Progress Tracker](../01-Knowledge-Vault/progress-tracker.md) → Log actions and outcomes
7. Plan tomorrow's single priority

## ⚡ Smart Commands Reference

### **Core Intervention Commands**
Use these intervention commands when patterns are detected:

| Command | Purpose | When to Use |
|---------|---------|-------------|
| `::cash_flow` | Force revenue thinking | Revenue avoidance pattern |
| `::break_loop` | Stop analysis paralysis | Overthinking, over-planning |
| `::focus_lock` | Prevent shiny object syndrome | New ideas while working |
| `::authenticity_check` | Align with core values | Decisions that feel "off" |

### **Enhanced Subagent Commands** 
Leverage specialized agents for complex tasks:

| Command | Agent | Purpose |
|---------|--------|---------|
| `::market_research` | Research Agent | Market analysis, competitive intelligence |
| `::technical_review` | Technical Agent | Architecture decisions, code review |
| `::revenue_optimization` | Business Agent | Financial modeling, strategy planning |
| `::content_sprint` | Content Agent | Marketing materials, documentation |
| `::process_audit` | Operations Agent | Workflow optimization, automation |

## 🔄 System Maintenance

### Daily
- Update [Current State](../01-Knowledge-Vault/current-state.md) (energy, priority)
- Log actions in [Progress Tracker](../01-Knowledge-Vault/progress-tracker.md)

### Weekly (`::weekly_plan`)
- Review what actually got DONE
- Set top 3 revenue priorities
- Identify patterns that interrupted progress
- Check for identity/value conflicts

### Monthly (`::values_checkpoint`)
- Review recent decisions for values alignment
- Update [Identity Profile](../01-Knowledge-Vault/identity-profile.md) for any evolution
- Assess authenticity of recent successes
- Update [Behavioral Patterns](../01-Knowledge-Vault/behavioral-patterns.md) success rates
