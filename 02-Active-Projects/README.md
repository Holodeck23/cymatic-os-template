# 📋 Active Projects

> **Time-bound, outcome-driven efforts with clear deadlines**

## How to Use This Folder

Each project gets its own markdown file using this template:

```markdown
# [Project Name]

**Status**: [Planning / In Progress / 80% Complete / Blocked]  
**Deadline**: [Date]  
**Revenue Impact**: [High / Medium / Low / None]  
**Authenticity Alignment**: [High / Medium / Low]

## Objective
[Clear, specific outcome you're working toward]

## Success Criteria
- [ ] [Measurable result 1]
- [ ] [Measurable result 2]  
- [ ] [Measurable result 3]

## Next Actions
1. **[Immediate next step]** - Due: [Date]
2. **[Following step]** - Due: [Date]
3. **[Third step]** - Due: [Date]

## Blockers
- [What's preventing progress]

## Resources Needed
- [Tools, skills, information required]

## Notes & Learning
[Capture insights as you work]
```

## Example Projects

Create files like:
- `launch-course-q4-2025.md`
- `youtube-strategy-implementation.md`  
- `email-automation-setup.md`
